# Простой консольный бот со списком задач
## Название
"ToDoBot" - бот, позволяющий формировать список своих задач и управлять им.

## Роли
В конечной версии приложения планируются 4 роли:
* Гость
* Обычный
* Премиум
* Админ

## Функции каждой роли
### Гость
* Запуск бота "/start".
* Регистрация.

### Обычный
* Создание задачи.
* Просмотр списка своих задач.
* Удаление задачи.

### Премиум
* Экспорт всего списка задач в .xlsx файл.

### Админ
* Проверка нагрузки на бота.
* Просмотр аналитики пользования ботом.
* Рассылка системных уведомлений.

## Базовые функции
* /start - запуск бота и последующая регистрация.
* /add - добавление задачи.
* /list - список задач.
* /remove - удаление задачи по её номеру (счёт начинается с 1).

## Примеры работы
### Регистрация
* User: /start
* Bot: Здравствуйте, это бот для создания списка задач. Введите ваше имя для регистрации.
* User: TON618
* Bot: Регистрация прошла успешно.

### Добавление задачи
* User: /add Купить хлеб
* Bot: Задача добавлена. Список задач можно узнать, введя команду /list

### Вывод списка задач
* User: /list
* Bot:
1. Купить хлеб

### Удаление задачи
* User: /remove 1
* Bot: Удалена задача под номером 1: Купить хлеб
